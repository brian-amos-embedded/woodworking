# Soda org 2 trial

The SketchUp source is `pantry.skp` (Library file
`libfile_5a88f77dd8388191b17ddc1ebeb677a3`). Direct Python extraction recovered
35 physical instances across eight definitions. The extracted geometry is
`soda-org-2.json` (Library file `libfile_75c49fa9bf908191b594383183eba958`).

Resume from `soda-org-2-R2.zip` (Library file
`libfile_b90e052f141081919d7925f7d0d42c93`). It contains the editable SolidCraft
model, a source-instance mapping, replay scripts, geometry verification,
plywood and hardwood schedules, machining data and a printable cut plan.
The standalone shop packet is `soda-org-2-cutlist.pdf` (Library file
`libfile_74332144c6148191be9c8fff5fd5cad6`).

The 26 × 18-1/8 × 36-1/4 inch design uses aligned shelf levels, 1/4 inch dado
depth, nominal 3/4 inch carcass plywood, a nominal 1/4 inch back and a
pocket-screwed maple face frame. The source back was 3/16 inch. The R2 plan
uses 1/8 inch kerf and 1/4 inch perimeter trim, one full 3/4 inch sheet and
two offcuts of different thicknesses. Model checks passed at R2 and in a
width and thickness variant. The cut plan is a nominal-stock draft. Update
measured stock and revalidate the lanes before making a fabrication revision.

R2 uses through side dados, side back grooves, and panel divider dados. The
shop packet labels rip widths on the sheet and shows part isometrics and
common-edge joinery dimensions.
